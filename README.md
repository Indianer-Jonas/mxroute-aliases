# mxroute-aliases
The firefox addon allows the creation of email aliases for MXroute.
Users can add a domain on which the aliases are based.
They have the option to create either a custom-named alias or a randomly generated one. Randomly generated aliases begin with "alias," followed by the current website's domain (if enabled), and a string of random letters and numbers (e.g., alias_addons.mozilla.org_sy1k5dali6@example.com).
The generated email address is automatically copied to the clipboard.

The addon and the developer are not associated with mxroute.

The user's login data for MXroute is routed through a proxy to avoid cross-origin errors. No user data is logged on the proxy server, you can also just host your own proxy server.
